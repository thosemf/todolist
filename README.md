# Todo List
A php app to keep track your to-do list

---

This app is the improved version of a project originally developed for the USK (Competency Certification Test). It is a simple CRUD and session php app to manage your to-do list.

### Features
1. Register and log into your account.
2. Create a to-do note.
3. Edit and Delete to-do notes.
4. Filter the notes by category, status, and favorite.
5. Search for notes by title.
